# 待办

记录待办事项的应用

## 已有功能

### 输入与添加
- 文本输入框添加任务，支持回车快捷添加
- 优先级选择：🔴高 / 🟡中 / 🟢低
- 截止日期选择器
- 任务上限 100 字符
### 任务操作
- 复选框勾选完成/取消完成
- 单个删除任务
- 全部完成（一键勾选所有任务）
- 清空已完成（带二次确认弹窗）
### 筛选与搜索
- 按状态筛选：全部 / 进行中 / 已完成
- 关键词实时搜索任务内容
### 排序
- 按截止日期升降序切换（无截止日期的排末尾）
### 数据展示
- 头部渐变进度条（完成百分比 + 已完成/总数）
- 三统计卡片：总任务数 / 已过期数 / 已完成数
- 任务卡左侧色条 + 徽章显示优先级
- 截止日期智能显示：今天到期 / 明天到期 / N 天后 / 已过期 N 天（过期红色高亮）
- 空状态提示（无任务 / 无搜索结果）
### 导出
- 导出为 txt 文件，包含勾选状态、优先级、截止日期，文件名带当天日期
### 数据持久化
- 所有数据自动保存到浏览器 localStorage，刷新/关闭后不丢失
